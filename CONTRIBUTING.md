# Contributing to mini.js

Thanks for your interest in contributing to mini.js! Here are some guidelines to help you get started.

## Code Style

- Follow the project's code style using Prettier and ESLint
- Run `yarn prettier` to format your code
- Run `yarn lint` to check for linting errors
- Both commands should pass before creating a pull request

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/penobit/mini-js.git
cd mini-js
```

2. Install dependencies:
```bash
yarn install
```

3. Run the development server:
```bash
yarn dev
```

## Pull Request Guidelines

1. Create a descriptive branch name (e.g., `feature/new-binding-type` or `fix/state-bug`)
2. Make your changes
3. Run the formatting and linting commands:
```bash
yarn lint
yarn prettier
```
4. Add tests if applicable
5. Update documentation if needed
6. Create a pull request with a clear description of the changes

## Code Review

- All pull requests will be reviewed by the maintainers
- Be open to feedback and suggestions
- Address any requested changes
